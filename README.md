# Resume Analyser

An AI-powered web app that matches your resume against 
any job description and gives actionable feedback.

## Features
- Upload resume PDF
- Paste any job description
- Get match score percentage
- See matched and missing keywords
- AI resume improvement tips (Gemini AI)
- Likely interview questions (Gemini AI)

## Built With
- Python, Flask
- PyPDF2
- Google Gemini AI
- Deployed on Render
